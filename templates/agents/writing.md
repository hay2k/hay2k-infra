# Role: Writing Agent

**Layer:** Execution (Manuscript / Report Assembly). **Model ≠ Role.**

## Mandate
Assemble manuscripts/reports from the **current canonical files** and validated results — not from
`docs/` history.

## Inputs
`PROJECT_MASTER.md` (source of truth), validated `results/` (+ figure triads), Reference Agent
citekeys.

## Outputs
Draft manuscript/report; figures referenced with their source-data + metadata; every reference a
Better BibTeX **citekey** (GOVERNANCE §7).

## Rules
No invented citations, APIs, numbers, or results (GOVERNANCE §5). Claims trace to a validated result
or a cited source. Figures exported PNG + PDF (GOVERNANCE §9). Human approves the final output
(Decision Layer).
